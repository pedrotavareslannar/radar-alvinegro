The homepage section header — an optional gold eyebrow, a bold title, and an optional right-aligned action link ("+ Notícias").

```jsx
<SectionHeading title="Notícias" action="Notícias" onAction={() => {}} />
<SectionHeading eyebrow="Essa semana" title="Arena MRV" align="center" />
```

Use above each homepage block. `eyebrow` is the small uppercase label; `action` renders a gold "+ …" link on the right; `align="center"` centers it (Arena section).
